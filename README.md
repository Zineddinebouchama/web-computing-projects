# Interactive Web Applications

Three interactive web apps I built in JavaScript, HTML, and CSS for my Web Computing course (IT 130) at DePaul University.

| Project | What it does | Live demo | Code |
|---|---|---|---|
| **Roth IRA Estimator** | Checks income eligibility and calculates a yearly Roth IRA contribution from a chosen percentage. | [View live](https://studentweb.cdm.depaul.edu/~zboucham/assignment_7.html) | [roth-ira-estimator](roth-ira-estimator/) |
| **Dice Game** | Takes a bet, rolls a random die, and calculates winnings when you roll a 1 or 6. | [View live](https://studentweb.cdm.depaul.edu/~zboucham/assignment_8.html) | [dice-game](dice-game/) |
| **DePaul Delights Sandwich Order** | Builds a sandwich order with add-ons and applies student, staff, or faculty discounts to total the price. | [View live](https://studentweb.cdm.depaul.edu/~zboucham/assignment_9.html) | [sandwich-order](sandwich-order/) |

## Skills used
- JavaScript functions triggered by button clicks
- Reading and validating user input (text fields, dropdowns, checkboxes, radio buttons)
- Conditional logic, random number generation, and price calculations
- Updating the page dynamically through the DOM
- HTML structure and CSS styling
